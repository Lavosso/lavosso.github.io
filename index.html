01a little context

I like understanding things by getting my hands on them.

My interests sit somewhere between software, AI, automation and physical systems. I am deliberately keeping the map wide for now, not because I want to collect technologies, but because I like seeing what happens when different fields start clicking together.

I learn something, build something, break something, write it down, and then usually find another thing I want to build.
